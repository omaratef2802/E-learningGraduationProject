# E-learningGraduationProject
# Smart E-Learning & Career Development Platform

## 📌 About the Project
A web-based platform designed to provide an interactive learning experience and support career development through online courses, assessments, and skill development opportunities.

## 🚀 Features
- **User Authentication:** Secure login and registration.
- **Role-Based Access Control:** Separate permissions for Students, Instructors, and Admins.
- **Course Management:** Browse courses, view course details, and manage learning content.
- **Learning Management:** Sections, lessons, quizzes, and learning progress tracking.
- **Wishlist & Cart:** Save courses and manage course selections.
- **Certificates:** Track achievements and earned certificates.
- **Dashboards:** Dedicated dashboards based on user roles.
- **Career Development:** Support skills assessment and career growth.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone <repository-url>
cd E-learningGraduationProject
```

### 2. Set Up the Back-end

```bash
cd Back-end
npm install
```

Configure the required environment variables, then start the server using the command defined in `package.json`.

### 3. Set Up the Front-end

Open a new terminal:

```bash
cd Front-end/e-learning
npm install
ng serve
```

Open the local URL displayed in the terminal to access the application.

## 👥 User Roles
- **Student:** Browse courses and track learning progress.
- **Instructor:** Create and manage courses and learning materials.
- **Admin:** Manage users and platform content.

## 🎯 Project Goal
To create an integrated learning environment that combines online education, skill assessment, and career development in one platform.
